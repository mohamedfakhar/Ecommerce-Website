# 🛒 Topico - E-commerce Store 
A modern, fully responsive e-commerce web application with a focus on clean UI and smooth user interactions.

## 🚀 Live Demo
**Check out the live site here:** [https://topoco.vercel.app/](https://topoco.vercel.app/)

---

## ✨ Key Features

* **Dynamic Shopping Cart:** A fully functional side-cart where users can add items, remove them, and see the total price update in real-time.
* **Product Filtering System:** Advanced filtering on the "All Products" page allowing users to sort by category, brand, and color.
* **Interactive UI/UX:**
    * Responsive **Hero Sliders** and **Product Carousels** using **Swiper.js**.
    * Smooth navigation with a functional sidebar for mobile users.
    * Professional Modal overlays for the shopping cart.
* **Multi-Page Experience:**
    * `Home Page`: Featured categories and best sellers.
    * `All Products`: With integrated filtering logic.
    * `Product Details`: Dedicated view for individual items.
    * `Auth Pages`: Custom-built Login and Signup interfaces.
    * `Checkout`: A streamlined checkout flow simulation.
* **Fully Responsive:** Crafted using CSS Flexbox and Grid to ensure a perfect look on mobiles, tablets, and desktops.

---

## 🛠️ Built With

* **HTML5:** Semantic markup for better SEO and accessibility.
* **CSS3:** Custom styling with a focus on modern layouts.
* **JavaScript (ES6+):** For the cart logic, product filtering, and DOM manipulation.
* **Swiper.js:** For high-performance touch sliders.
* **FontAwesome:** For high-quality vector icons.

---

## 📂 Project Highlights

* **Logic-Driven:** The site isn't just static; it handles product data dynamically to update the UI.
* **User Centric:** Includes features like a "Back to Top" button and intuitive search bar placeholders to enhance usability.
* **Clean Code:** Organized folder structure separating CSS and JS for better maintainability.
